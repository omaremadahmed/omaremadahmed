Methodology, Data Sources & Rate Limiting

This analytics application connects directly to the official unauthenticated GitHub REST API (api.github.com) to retrieve public metadata on client initialization. To prevent quota exhaustion (60 requests per hour per IP on unauthenticated endpoints), the client stores verified payloads in localStorage with a 15-minute Time-To-Live (TTL).

Reported Metrics:
  • Public repository counts, star counts, and fork counts.
  • Primary programming language as determined by GitHub Linguist.
  • Repository creation and last-updated ISO 8601 timestamps.
Privacy & Architecture Boundaries:
  • Zero private repository code, branches, or tokens are exposed.
  • House Platform is presented as an architectural model per design policy.
  • No external tracking scripts, third-party CDNs, or telemetry pixels.
